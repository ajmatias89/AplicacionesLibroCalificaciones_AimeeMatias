# Laboratorio 2 - Aplicaciones LibroCalificaciones

Repositorio correspondiente al **Laboratorio 2**, desarrollado a partir de los ejercicios realizados en clase el **24 de agosto**.

## Descripción

Este laboratorio contiene diferentes aplicaciones de consola desarrolladas en **C#** utilizando la clase `LibroCalificaciones`. Los ejercicios permiten practicar conceptos fundamentales de la programación orientada a objetos mediante la creación y modificación de objetos que representan libros de calificaciones para diferentes cursos.

A través de las distintas aplicaciones se implementan progresivamente elementos como métodos, atributos, constructores y propiedades.


## Conceptos utilizados

* Clases
* Objetos
* Métodos
* Variables de instancia
* Constructores
* Propiedades
* `get` y `set`
* Entrada y salida de datos por consola
* Programación orientada a objetos
